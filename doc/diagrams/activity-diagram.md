# Activity Diagram — ขั้นตอนจองนัดหมาย

แสดงเส้นทางผู้ใช้ทั่วไป รวมการเพิ่มสัตว์เลี้ยงก่อนจอง โดยอิงหน้า Booking และ Guest Appointment API.

```mermaid
flowchart TD
    A([เริ่ม]) --> B[เปิดหน้าจองนัดหมาย]
    B --> C[ค้นหาหรือระบุเจ้าของสัตว์เลี้ยง]
    C --> D{พบข้อมูลเจ้าของ?}
    D -- ไม่พบ --> E[ลงทะเบียนเจ้าของ]
    E --> F[โหลดรายการสัตว์เลี้ยง]
    D -- พบ --> F
    F --> G{มีสัตว์เลี้ยง?}
    G -- ไม่มี --> H[เปิดหน้าเพิ่มสัตว์เลี้ยง]
    H --> I[บันทึกสัตว์เลี้ยง]
    I --> F
    G -- มี --> J[เลือกสัตว์เลี้ยง ประเภทบริการ และสัตวแพทย์]
    J --> K[เลือกวันและเวลา]
    K --> L[ส่งคำขอจอง]
    L --> M{ข้อมูลถูกต้องและเวลาว่าง?}
    M -- ไม่ --> N[แสดงข้อผิดพลาดและให้แก้ไข]
    N --> J
    M -- ใช่ --> O[บันทึกนัดหมาย]
    O --> P[แสดงผลสำเร็จ]
    P --> Q([จบ])
```

หมายเหตุ: ขั้นตอนตรวจสอบช่วงเวลาที่ว่างเป็นความรับผิดชอบของ Service/Policy ไม่ใช่แค่การตรวจในหน้าเว็บ.
